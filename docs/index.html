Sync — save this ledger to the database on GitHub

Save to GitHub commits this table over the published database, so the public page shows it. Reload published throws away this browser's copy and re-reads the committed file. Use a fine-grained token limited to this one repo with Contents: Read and write — it's stored in this browser's localStorage, never committed and never sent anywhere but api.github.com. Anyone who can use this browser profile can read it, so don't do this on a shared machine, and revoke the token on GitHub if you're unsure. Visitors to the public page can read the ledger but have no token, so they can't change it. The same token covers the Chase tab.

Cells work like a spreadsheet. Click to select, drag or ⇧+click for a range, ⌘C / ⌘V / ⌘X to copy, paste, and cut blocks — a paste spills right and down from the selected cell and adds rows if it needs them. ⌘A selects everything, ⌫ clears the selection. Just start typing to overwrite a cell, or ↩ / double-click to edit it; ↩ commits and moves down, ⇥ moves right, esc reverts. Arrow keys move around, and the selection's total shows next to the toolbar.
